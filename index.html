Le rapport reprend les lignes affichées. Les markers de changement se collent dans un fichier .txt à importer dans la nouvelle séquence (Markers > Import) : rouge supprimé, vert nouveau, jaune déplacé, magenta modifié.

Les timecodes sont comparés en images à partir de la cadence choisie (calcul sans correction drop frame). Un marker supprimé est placé à sa position dans l'ancienne séquence. Rien n'est envoyé : la comparaison se fait dans ton navigateur.
